# Heatwave Intelligence System — Clean Merged Website

This package merges the WDL mini-project and the Heatwave Prediction JS + jQuery project.

## Primary base
The mini-project remains the majority of the interface and functionality: the dark sidebar, dashboard metrics, sortable regional table, seven-day forecast selector, subscription experience, and interactive India hotspot map.

## Integrated heatwave-project material
The merged site also brings in the companion project's severe-alert bulletin, departure-from-normal operational station table, data/forecast workflow, stakeholder roles, system objective, awareness/IMD resource page, and jQuery interactions.

## Cleanup
Duplicate navigation systems and duplicate page versions were removed. The old Portal Directory / Navigation page and separate Alert Details page are intentionally consolidated into the main pages. Missing MP4/MP3 references from the source package were removed so the final site does not contain broken media controls.

All figures are sample/demo data and the site is not an official warning service.

Open `index.html` to start.
